## 方法一：VS Code 自动端口转发（最推荐，最简单）
如果你是用 VS Code 的 Remote - SSH 插件连接服务器的，它会自动帮你处理这一切。

在 VS Code 底部状态栏找到 Ports（端口） 面板（如果没有，点击右键勾选）。

你会看到 5173 端口已经被自动转发了。

直接在本地浏览器访问：http://localhost:5173 即可。

## 方法二：SSH 隧道（手动转发）
如果你是直接在终端用 ssh 命令连接的，可以在连接时增加一个端口转发参数。

在本地电脑的终端执行（先退出当前的 SSH）：

```Bash
ssh -L 5173:localhost:5173 martina@服务器IP
```

含义： 把远程服务器的 5173 端口映射到你本地主机的 5173 端口。
查看： 保持这个终端不要关，在本地浏览器打开 http://localhost:5173。
